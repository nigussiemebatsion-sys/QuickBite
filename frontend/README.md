# QuickBite Frontend

Simple restaurant frontend built with only HTML, CSS, and Vanilla JavaScript.

## Run

Open `index.html` in a browser, or use VS Code Live Server.

## Structure

- `home.html` — landing page
- `menu.html` — all foods
- `food-details.html` — selected food and quantity
- `cart.html` — localStorage cart
- `checkout.html` — checkout UI
- `order-confirmation.html` — confirmation screen
- `login.html` / `signup.html` — frontend-only forms
- `css/style.css` — shared styles
- `js/app.js` — food data + shared cart functions
- `js/menu.js` — menu rendering
- `js/food-details.js` — food details
- `js/cart.js` — cart operations
- `js/checkout.js` — checkout logic
